# 🍳 Каталог Рецептов — Backend

**Умный backend для сайта с подбором рецептов по ингредиентам** ✨

---

## О проекте

Проект представляет собой REST API для каталога рецептов с **мощным поиском по имеющимся у пользователя ингредиентам**.  
Позволяет находить рецепты даже если у вас нет всех продуктов.

### ✨ Основные возможности
- Умный поиск рецептов с **расчётом процента совпадения**
- Поддержка обязательных ингредиентов
- Полноценный CRUD рецептов и ингредиентов
- Чистая и понятная архитектура
- Автоматическая Swagger-документация

---

## 🚀 Быстрый запуск

### 1. Клонирование проекта

```bash
git clone https://github.com/happygame406/recipe_catalog_backend.git
cd recipe_catalog_backend
```

### 2. Создание виртуального окружения

```bash
python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # Linux / macOS
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Создание базы данных + тестовые рецепты

```bash
python seed.py
```

### 5. Запуск сервера

```bash
uvicorn main:app --reload
```

Сервер запустится по адресу: **http://127.0.0.1:8000**

**Интерактивная документация**: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs) 📘

## 🔥 Основные возможности API

### 1. Поиск рецептов по ингредиентам (самое важное!)

**POST** `/recipes/search/by-ingredients`

```json
{
  "user_ingredients": ["курица", "рис", "морковь", "лук"],
  "min_match_percent": 40.0,
  "limit": 10
}
```

**Что возвращает:**
- Список рецептов с **процентом совпадения**
- Список недостающих ингредиентов
- Сортировка от лучшего совпадения

---

**Быстрый поиск (GET):**

```http
GET /recipes/search/quick?ingredients=курица,рис,морковь&min_match=30&limit=8
```

---

### 2. Работа с рецептами

| Метод | Эндпоинт              | Что делает                  |
|-------|-----------------------|-----------------------------|
| GET   | `/recipes/`           | Все рецепты                 |
| GET   | `/recipes/{id}`       | Один рецепт                 |
| POST  | `/recipes/`           | Создать рецепт              |
| PUT   | `/recipes/{id}`       | Обновить рецепт             |
| DELETE| `/recipes/{id}`       | Удалить рецепт              |

### 3. Ингредиенты

- `GET /ingredients/` — список всех ингредиентов
- `POST /ingredients/` — добавить новый

## 📌 Примеры запросов

### Пример 1: Хороший подбор

```json
{
  "user_ingredients": ["курица", "картофель", "морковь"],
  "min_match_percent": 50.0,
  "limit": 5
}
```

### Пример 2: Показать всё

```json
{
  "user_ingredients": [],
  "min_match_percent": 0.0,
  "limit": 20
}
```

```json
{

  "cooking_time": 90,
  "ingredients": ["свёкла", "капуста", "картофель", "морковь", "говядина"]
}
```
